# 最強ミュウツーオプチャ杯 スコアチェッカー

ポケモンスリープの独自イベント「最強ミュウツーオプチャ杯（The Ultimate Mewtwo OpenChat Cup）」用スコア判定Webアプリケーションです。

うなこ杯（The Ultimate Unako Championship）と同じ仕組みで、対象ポケモンをミュウツーに変えたものです。

## 🌟 特徴
- **📸 スクショ自動認識**: ポケモンのステータス画面（スクリーンショット）をアップロードするだけで、SP・性格・食材・サブスキル等を自動抽出！
- **🧮 正確な自動スコアリング**: Lv70(1割引)・Lv80(3割引)やコンボボーナス（3種の神器、こてい個体、オール金、地球は青かった、ほおばりセット、ギガ枕EX、スキ確ハッピーセット）、SP1000・ゾロ目・キリ番などを完全網羅。
- **📱 スクショ最適化デザイン**: スマホ画面1枚で綺麗にスクショが撮れる洗練された結果カードレイアウト。
- **📝 完全選択式・タップ操作**: 手動での微調整もドロップダウンやチェックボックスで片手でサクサク入力可能。
- **💾 履歴保存**: 端末内（localStorage）に個体のスコア履歴を保存・管理。

## 🐈‍⬛ うなこ杯からの変更点
- 対象はミュウツー1種のみ。無進化なので**直取りボーナス（ナカヌチャン/デカヌチャン）は廃止**。
- **リサ配ボーナスも廃止**。特別ボーナスは「色違い(+350)」「初回注文ボーナス(2匹目)(+100)」の2つ。
  （FL10以内ボーナスは、ほとんどの個体がFL10以内になるため 2026-09-13 に廃止し、初回注文ボーナスに置きかえた）
- 満点が下がったぶん、**ミュウが現れる点数は600点**（うなこ杯は800点）。
- 配色はミュウツーに合わせた紫基調。
- 食材パターン ABA(-30) の表示から「ギール」の語を削除（点数は-30のまま）。

## 🖼️ 画像について
- `mewtwo.png` … ヘッダー中央と結果カードのアイコン。月をバックにしたミュウツーの1枚絵（元ファイルは `Claude/mewtwo/mew2.png`、512pxに縮小）。切り抜き画像ではないので CSS で角を丸めている。
- `mew.png` … ヘッダー左右のミュウ。600点以上で現れて交互に点滅する。左側は CSS の `scaleX(-1)` で左右反転。
  さらに600点を超えた瞬間には、画面いっぱいの演出（`#mewCelebrate`、大きなミュウ2匹＋「ミュウが現れた！」）も出る。タップか7秒で閉じる。解析後に下を見ている人がヘッダーのミュウに気づかないため（2026-09-17追加）。
- `icon_soy.png` / `icon_corn.png` / `icon_potato.png` … 食材アイコン（大豆とコーンは2026-09-14に絵文字を描いて作ったもの。ポテトだけゲーム画面の切り抜き。`icon_tomato.png` / `icon_cacao.png` は使っていないが残してある）

### mew.png の加工について
2026-09-13 に、濃いピンクの線で描かれた新しい絵（元ファイルは `Claude/mewtwo/mew.jpg`、白背景のJPEG）に差し替えた。
JPEGは背景を透明にできないので、Pillow で以下を施した PNG を置いている。

1. 四隅からの flood fill で「絵の外側の白」だけを特定（ミュウの体の中の白は残す）
2. 外側は「白さ」のぶんだけ透明にし、白と混ざった色を割り戻す（まわりのぼんやりした光が白いフチにならずに残る）
3. 余白を切り詰め、高さ384pxに縮小（表示は92pxなので約4倍で保持）

絵じたいに濃い線と光があるので、`style.css` の `.hibiscus-lamp.lit` と `@keyframes lampAlt` の `filter` は
薄いピンクのふちどり＋紫の光だけにしてある。強くしすぎると絵の中が白くとんで見える。
差し替え前の画像は `Claude/mewtwo/mew_サイト用_旧.png` に退避してある。

## 🍅 食材を変えるとき
食材の定義は **`ingredients-setting.js` の1ファイルに集約**してある。
ここを直せば、選択メニュー・バッジ・得点内訳・投稿文・保存画像がまとめて変わる。

プログラミングに慣れていない人向けの詳しい手順は **`食材の変えかた.txt`** に書いてある。

2026-09-14 に本番の食材（ワカクサ大豆 / ワカクサコーン / ほっこりポテト）に差し替えずみ。

スクショからの食材の自動読み取りは、**大豆・コーン・ポテトの3つに対応ずみ**（2026-09-14）。
テスト用スクショ `Claude/mewtwo/mew2test1〜5.jpg` の5枚すべてで、食材・サブスキル・せいかく・SPが正しく読めることを確認してある。

### 食材の色を測る（別の食材に変えたとき）
食材を別のものに変えると、その食材の色データが無いので自動読み取りが当たらなくなる。
色データは `vendor/pokesleep-vision/ingredients.js` の `PROTOTYPES` にある。足すときは：

1. `サイトを開く.bat` でサイトを開き、F12 でコンソールを出す
2. その食材が写っているステータス画面のスクショを、サイトと同じフォルダに置く
3. コンソールで次を実行すると、スロットごとの `hue`（24個の数字）が出る
   ```js
   const V = await import('./vendor/pokesleep-vision/index.js');
   const img = new Image(); img.src = 'スクショ.jpg'; await img.decode();
   const c = document.createElement('canvas'); c.width = img.naturalWidth; c.height = img.naturalHeight;
   c.getContext('2d').drawImage(img, 0, 0);
   const px = { w: c.width, h: c.height, data: c.getContext('2d').getImageData(0, 0, c.width, c.height).data };
   V.detectLayout(c).ingredientSlots.map(b => V.describeIcon(px, b).hue.map(v => +v.toFixed(3)));
   ```
4. 出てきた数字を `PROTOTYPES` に `{ name: '食材名', hue: [...] }` として足す（何枚かの平均にするとよい）
5. `ocr.js` は `ingredients-setting.js` の name をそのまま候補に渡すので、name をぴったり合わせること

## 🧮 得点ルール（2026-09-13 ミュウツー配点表）
配点はすべて `scoring.js` にある。数字を変えるときは以下の場所を直す。

- **サブスキル** … `SUB_SKILL_POINTS`。きのみS/おてぼ/睡眠ボ 150、リサボ/ゆめボ/げんボ/スキレベM 80、スキレベS 40、スピM 120、スピS 80、スキM 200、スキS 100、食材M 0、食材S 10、所持L 100、所持M 50、所持S 30。
  `isGold`＝金スキル、`isBlue`＝青スキル（青: スキレベS/スピM/スキM/食材M/所持L/所持M）。
- **食材パターン** … `INGREDIENT_PATTERN_POINTS`。AAA 100、ABB 60、ABC 20、AAB 10、AAC 10、ABA -30。
- **性格** … `NATURE_SCORES`。↑↑: スキル100/EXP90/スピ70/げんき20/食材-30。↓↓: 食材+30/げんき0/スピ-50/EXP-50/スキル-100。
- **SP** … `calculateSpBonus`。1000ちょうど +200、ゾロ目 +100、キリ番(下2桁00) +50。
- **特別ボーナス** … 色違い +350、初回注文ボーナス(2匹目) +100。
- **コンボ** … `calculateTotalScore` 内の `SKILL_SET_COMBOS` と、その下の「5枠ぜんぶ同じ色」の判定。
  3種の神器(おてぼ/きのみS/睡眠ボ) 100、こてい個体(所持S/M/L) 144、ギガ枕EX(睡眠ボ/ゆめボ/リサボ) 30、
  ほおばりセット(食材M/食材S＋食材↑↑) 50、スキ確ハッピーセット(スキM/スキS＋スキル↑↑) 80、
  オール金(5枠すべて金) 200、地球は青かった(5枠すべて青) 30。
- **割引** … サブスキル本体の点だけ、Lv.70枠は1割引、Lv.80枠は3割引。**コンボボーナスには割引を掛けない**（Lv.80枠のスキルで満たしても満額）。
- コンボは重なって付く（例: オール金の5つの中に 3種の神器 と ギガ枕EX が入っていれば、その2つも同時に加点）。
