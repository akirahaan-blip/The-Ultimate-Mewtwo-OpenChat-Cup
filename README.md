# 最強ミュウツーオプチャ杯 スコアチェッカー

ポケモンスリープの独自イベント「最強ミュウツーオプチャ杯（The Ultimate Mewtwo OpenChat Cup）」用スコア判定Webアプリケーションです。

うなこ杯（The Ultimate Unako Championship）と同じ仕組みで、対象ポケモンをミュウツーに変えたものです。

## 🌟 特徴
- **📸 スクショ自動認識**: ポケモンのステータス画面（スクリーンショット）をアップロードするだけで、SP・性格・食材・サブスキル等を自動抽出！
- **🧮 正確な自動スコアリング**: Lv70(1割引)・Lv80(3割引)やコンボボーナス（3種の神器、こてい個体、オール金）、SPゾロ目・キリ番などを完全網羅。
- **📱 スクショ最適化デザイン**: スマホ画面1枚で綺麗にスクショが撮れる洗練された結果カードレイアウト。
- **📝 完全選択式・タップ操作**: 手動での微調整もドロップダウンやチェックボックスで片手でサクサク入力可能。
- **💾 履歴保存**: 端末内（localStorage）に個体のスコア履歴を保存・管理。

## 🐈‍⬛ うなこ杯からの変更点
- 対象はミュウツー1種のみ。無進化なので**直取りボーナス（ナカヌチャン/デカヌチャン）は廃止**。
- **リサ配ボーナスも廃止**。特別ボーナスは「色違い(+350)」「FL10以内(+100)」の2つ。
- 満点が下がったぶん、**ミュウが現れる点数は600点**（うなこ杯は800点）。
- 配色はミュウツーに合わせた紫基調。
- 食材パターン ABA(-30) の表示から「ギール」の語を削除（点数は-30のまま）。

## 🖼️ 画像について
- `mewtwo.png` … ヘッダー中央と結果カードのアイコン。月をバックにしたミュウツーの1枚絵（元ファイルは `Claude/mewtwo/mew2.png`、512pxに縮小）。切り抜き画像ではないので CSS で角を丸めている。
- `mew.png` … ヘッダー左右のミュウ。600点以上で現れて交互に点滅する。左側は CSS の `scaleX(-1)` で左右反転。
- `icon_tomato.png` / `icon_cacao.png` / `icon_potato.png` … 食材アイコン

### mew.png の加工について（重要）
元絵（`Claude/mewtwo/mew.png` に無加工で保存）は **白背景＋うすいピンク＋まわりに大きな余白** で、
明るい背景のこのサイトではほとんど見えなかった。そこで Pillow で以下を施したものを置いている。

1. 四隅からの flood fill で白背景を透明化
2. 余白を切り詰め（1206x1087 → 558x967。ミュウ自体が約2倍の大きさに）
3. 彩度 3.2倍 / 明度 0.94倍 / コントラスト 1.1倍

さらに `style.css` の `.hibiscus-lamp.lit` と `@keyframes lampAlt` で、
濃いピンク `rgba(196, 40, 126, ...)` の `drop-shadow` を2枚重ねてふちどりにしている。
**このふちどりを消すと、また背景に溶けて見えなくなる。**

## 🍅 食材を変えるとき
食材の定義は **`ingredients-setting.js` の1ファイルに集約**してある。
ここを直せば、選択メニュー・バッジ・得点内訳・投稿文・保存画像がまとめて変わる。

プログラミングに慣れていない人向けの詳しい手順は **`食材の変えかた.txt`** に書いてある。

⚠️ 食材を変えると、スクショからの**食材の自動読み取りだけ**が当たらなくなる
（`vendor/pokesleep-vision/ingredients.js` の PROTOTYPES に色相の実測値が必要なため）。
SP・性格・サブスキルの読み取りには影響しない。食材は手動で選んでもらう運用になる。

## 💻 ローカルで動かす
ES modules を使っているので `index.html` を直接ダブルクリックしても動かない。
**`サイトを開く.bat`** をダブルクリックすると、簡易サーバーが立ち上がってブラウザが開く。

## ⚠️ 得点ルールについて
サブスキル配点・性格補正・食材パターンの配点は、いまのところうなこ杯と同じ数値のまま。
必要なら `scoring.js` の `SUB_SKILL_POINTS` / `INGREDIENT_PATTERN_POINTS` を調整する。
