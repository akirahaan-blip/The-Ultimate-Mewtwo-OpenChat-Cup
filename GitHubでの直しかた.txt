============================================================
 公開したサイトを、あとから自分で直す手順
 最強ミュウツーオプチャ杯 スコアチェッカー
============================================================

パソコンのファイルを触らなくても、GitHubのサイト上だけで直せます。
コマンドは1つも使いません。ブラウザだけでできます。


------------------------------------------------------------
 このサイトの住所（ブックマークしておくと楽です）
------------------------------------------------------------

  ■ 参加者に配る公開ページ
    https://akirahaan-blip.github.io/The-Ultimate-Mewtwo-OpenChat-Cup/

  ■ 中身を直す場所（GitHubの管理画面）
    https://github.com/akirahaan-blip/The-Ultimate-Mewtwo-OpenChat-Cup


------------------------------------------------------------
 【基本の流れ】どのファイルを直すときも同じ
------------------------------------------------------------

 1. 上の「中身を直す場所」のURLをブラウザで開く
    （ログインを求められたら、いつものGitHubのアカウントで入る）

 2. ファイルの一覧が出るので、直したいファイル名をクリックする

 3. 画面の右のほうにある「鉛筆マーク（✏️）」をクリックする
    → 文字が打てる状態になります
    ※ 鉛筆マークが見あたらないときは、ログインできていません。
      右上の「Sign in」からログインしてください。

 4. 直したいところの文字を書きかえる

 5. 画面右上の緑色のボタン「Commit changes...」をクリック

 6. 小さい窓が出るので、そのまま緑の「Commit changes」をクリック
    （上の入力欄は「何を直したかのメモ」です。空でもかまいません）

 7. 1〜2分待つ

 8. 公開ページを開いて、直っているか確認する
    → 変わっていないときは、キーボードの Ctrl と F5 を同時に押す
      （ブラウザが覚えている古い画面を捨てて読み直す操作です）


------------------------------------------------------------
 【よくある直し1】食材を変える  ★これが本命★
------------------------------------------------------------

 1. 上の【基本の流れ】の手順で ingredients-setting.js を開く

 2. 下のほうにある、この3行の " " の中の文字を書きかえる

    { code: "A", name: "あんみんトマト",   short: "トマト",     emoji: "🍅", image: "icon_tomato.png" },
    { code: "B", name: "リラックスカカオ", short: "カカオ",     emoji: "🍫", image: "icon_cacao.png" },
    { code: "C", name: "ほっこりポテト",   short: "じゃがいも", emoji: "🥔", image: "icon_potato.png" }

    ※ 何をどう書きかえるかは、同じフォルダの
      「食材の変えかた.txt」に詳しく書いてあります。
      （このファイルはGitHubの一覧からも読めます）

    ※ code の A / B / C は絶対に変えないこと。
    ※ " と , を消さないこと。

 3. Commit changes して保存

 4. つづけて index.html も開いて、下の【よくある直し4】をやる
    （これをやらないと、直したのに古いままに見える人が出ます）


------------------------------------------------------------
 【よくある直し2】食材アイコンの画像を差しかえる
------------------------------------------------------------

 1. 「中身を直す場所」のURLを開く

 2. 画面右上あたりの「Add file」ボタン → 「Upload files」を選ぶ

 3. 新しい画像をドラッグして放り込む
    ★ ファイル名を icon_tomato.png / icon_cacao.png / icon_potato.png と
      まったく同じにしておくと、上書きされて自動で入れかわります。
      （ingredients-setting.js を直さなくて済みます）

 4. 下の緑の「Commit changes」をクリック

 5. index.html も【よくある直し4】をやる


------------------------------------------------------------
 【よくある直し3】ミュウが出てくる点数を変える（いまは600点）
------------------------------------------------------------

 1. 【基本の流れ】で app.js を開く

 2. 上から3分の2くらいのところにある、この行を探す
    （ブラウザの検索 Ctrl+F で「LAMP_THRESHOLD」と打つと早いです）

      const LAMP_THRESHOLD = 600;

 3. 600 を好きな数字に変えて Commit changes

 4. index.html も【よくある直し4】をやる


------------------------------------------------------------
 【よくある直し4】直したことをブラウザに伝える（毎回やること）
------------------------------------------------------------

★ これを忘れると、前にページを開いたことがある人の画面が
  古いままになります。必ずセットでやってください。

 1. 【基本の流れ】で index.html を開く

 2. 上のほう（9行目あたり）のこの行を探す

      <link rel="stylesheet" href="style.css?v=18">

    「18」の数字を「19」に増やす

 3. いちばん下のほうのこの行も探す

      <script type="module" src="app.js?v=18"></script>

    こちらも「18」を「19」に増やす

 4. Commit changes

 ★ 数字は前と違えばなんでもOKです。次に直すときは20、その次は21…と
   増やしていってください。


------------------------------------------------------------
 【困ったとき】直したらページが真っ白になった
------------------------------------------------------------

あわてなくて大丈夫です。**直す前の状態に丸ごと戻せます。**

 1. 「中身を直す場所」のURLを開く

 2. ファイル一覧の上のほうにある「Commits」（時計みたいなマーク）を
    クリックする → いままでの変更の一覧が出ます

 3. おかしくなる前の変更（1つ前のもの）の右にある「<>」マークをクリック
    → その時点のファイル一覧が見られます

 4. 壊したファイル（たぶん ingredients-setting.js）をクリックして開く

 5. 右上の「Copy raw file」（コピーのマーク）をクリック

 6. いまのファイルを【基本の流れ】で開いて、中身を全部消して、
    Ctrl+V で貼りつけて Commit changes

 → 元に戻ります。
