============================================================
 食材の変えかた（Claudeがいなくても、ひとりで直せる手順）
 最強ミュウツーオプチャ杯 スコアチェッカー
============================================================

※2026-09-14 に本番の食材「大豆・コーン・じゃがいも」に直しずみです。
  もし食材をまた変えることになったら、このとおりにやれば直せます。所要 10分くらいです。


------------------------------------------------------------
 【はじめに】直すのは 1つのファイルだけです
------------------------------------------------------------

  ingredients-setting.js  ← このファイルだけ

このファイルの中の3行を書きかえると、

  ・食材の選択メニュー（プルダウン）
  ・食材のアイコンと名前が出ている小さい枠
  ・得点の内訳（「AAA (トマト/トマト/トマト) +100」の部分）
  ・X（Twitter）に貼る投稿文
  ・「画像を保存」で作られる画像

これ全部が、まとめて変わります。ほかのファイルは触らないでください。


------------------------------------------------------------
 【手順1】念のためバックアップを取る
------------------------------------------------------------

1. エクスプローラー（画面下のフォルダのアイコン）を開く
2. C: → ユーザー → oauao → Claude → それ以外 →
   The-Ultimate-Mewtwo-OpenChat-Cup フォルダを開く
3. その中の  ingredients-setting.js  を1回クリックして選ぶ
4. キーボードで Ctrl+C → そのまま Ctrl+V
   → 「ingredients-setting - コピー.js」ができる
   ★ これが、失敗したとき戻すための控えです。

   ※ もし直したあとサイトが真っ白になったら、
      いま作った「コピー」のほうの名前を
      「ingredients-setting.js」に戻せば元どおりです。
      （元のファイルは先に消すか、名前を変えておいてください）


------------------------------------------------------------
 【手順2】ファイルをメモ帳で開く
------------------------------------------------------------

1. ingredients-setting.js を「右クリック」する
2. 「プログラムから開く」を選ぶ
   （見あたらないときは「その他のオプションを確認」を先にクリック）
3. 「メモ帳」を選ぶ

   ★ ダブルクリックはしないでください。
     .js ファイルはダブルクリックすると「実行」されてしまい、
     おかしなことが起きる場合があります。


------------------------------------------------------------
 【手順3】3行を書きかえる
------------------------------------------------------------

ファイルの下のほうに、こう書いてある3行があります。

  { code: "A", name: "ワカクサ大豆",     short: "大豆",       emoji: "🫘", image: "icon_soy.png" },
  { code: "B", name: "ワカクサコーン",   short: "コーン",     emoji: "🌽", image: "icon_corn.png" },
  { code: "C", name: "ほっこりポテト",   short: "じゃがいも", emoji: "🥔", image: "icon_potato.png" }

この " " （ダブルクォーテーション）の中の文字だけを書きかえます。

  code  … A / B / C。★ここは絶対に変えないでください★
          A＝Lv.1で最初から持っている食材
          B＝Lv.30で増える2種類目
          C＝Lv.60で増える3種類目
          得点表（AAA=100点、ABA=-30点…）がこの記号で書かれているので、
          ここを変えると点数がめちゃくちゃになります。

  name  … ゲームに出ている正式な名前。
          例:「とくせんリンゴ」「げきからハーブ」「あじわいキノコ」
          スクショの自動読み取りで名前をつき合わせるのに使います。

  short … 画面や投稿文に出る短い名前。
          例:「リンゴ」「ハーブ」「キノコ」
          ★4文字くらいまで。長いと画面から文字がはみ出します。

  emoji … 選択メニューの先頭に出る絵文字。何でもかまいません。
          絵文字を出すには、Windowsキー と . （ピリオド）を
          同時に押すと絵文字の一覧が出ます。

  image … 食材アイコンの画像ファイル名。→ 手順4で説明します。


  ■ 書きかえた例（ミュウツーの食材がリンゴ／ハーブ／キノコだった場合）

  { code: "A", name: "とくせんリンゴ", short: "リンゴ", emoji: "🍎", image: "icon_a.png" },
  { code: "B", name: "げきからハーブ", short: "ハーブ", emoji: "🌿", image: "icon_b.png" },
  { code: "C", name: "あじわいキノコ", short: "キノコ", emoji: "🍄", image: "icon_c.png" }


  ■ 壊さないための注意（ここだけ守ればまず大丈夫）

  ・" " （ダブルクォーテーション）は消さない。中の文字だけ変える。
  ・行のおしりの , （カンマ）は消さない。
    ただし いちばん下の C の行だけは、もともとカンマがありません。
    そのままにしておいてください。
  ・全角の「”」ではなく、半角の「"」を使う。
    メモ帳で普通に打てば半角になります。
  ・{ } や [ ] は触らない。

4. 書きかえたら Ctrl+S で保存する
   → メモ帳のタイトルの左にある「*」印が消えれば保存できています


------------------------------------------------------------
 【手順4】食材アイコンの画像を入れかえる
------------------------------------------------------------

いまフォルダに入っている画像はこの3つです。

  icon_soy.png    （大豆）
  icon_corn.png   （コーン）
  icon_potato.png （じゃがいも）
  （icon_tomato.png / icon_cacao.png も残っていますが、いまは使っていません）

■ かんたんな方法（おすすめ）

  新しい食材のアイコン画像を用意して、
  上と まったく同じ名前 で保存し直して上書きすれば、
  手順3の image のところは変えなくてOKです。
  （ファイル名が大豆のままなのは気持ち悪いですが、動きます）

■ きちんとやる方法

  新しい画像を「icon_a.png」「icon_b.png」「icon_c.png」などの
  名前でこのフォルダに入れて、手順3の image をその名前に書きかえます。

■ 画像がどうしても用意できないとき

  古い画像のまま（大豆の絵のまま）でも、サイトは問題なく動きます。
  絵が合っていないだけです。あとから差しかえられます。

  ※ 画像は 正方形・小さめ（100×100ピクセルくらい）・PNG形式 が
    きれいに出ます。


------------------------------------------------------------
 【手順5】直したことをブラウザに伝える（これを忘れがち）
------------------------------------------------------------

ブラウザは、前に見たファイルを覚えていて、
直しても古いままを表示することがあります。それを防ぎます。

1. index.html を「右クリック」→「プログラムから開く」→「メモ帳」
2. 上のほう（9行目あたり）に

      <link rel="stylesheet" href="style.css?v=18">

   と書いてある行があります。
   この「18」の数字を「19」に増やす。

3. 下のほう（いちばん下のあたり）に

      <script type="module" src="app.js?v=18"></script>

   と書いてある行もあります。こちらも「18」→「19」に増やす。

4. Ctrl+S で保存

   ★ 数字は 19 でも 20 でも 99 でもかまいません。
     「前と違う数字にする」ことだけが大事です。
     次に直すときは、また1つ増やしてください。


------------------------------------------------------------
 【手順6】ちゃんと変わったか確かめる
------------------------------------------------------------

1. フォルダの中の「サイトを開く.bat」をダブルクリック
2. ブラウザが開いたら、画面を下にスクロールして
   「食材構成 (Lv.1 / Lv.30 / Lv.60)」のプルダウンを見る
   → 新しい食材の名前になっていれば成功です
3. 上の結果カードの「食材構成」のところも見る
   → 「AAA (リンゴ/リンゴ/リンゴ)」のように変わっていれば成功
4. 確認が終わったら、黒い画面を右上の × で閉じる

  ■ 画面が真っ白になったら
    どこかで " や , を消してしまっています。
    手順1で作ったバックアップのコピーに戻して、やり直してください。


============================================================
 ★★ 大事な注意 ★★  自動読み取り（スクショ）について
============================================================

食材を変えると、

  「スクショ画像をアップロード」で読み取ったとき、
   食材だけが正しく判定されなくなります。

理由：
  このサイトは食材アイコンの「色」を見分けて判定しています。
  色を測ってあるのは 大豆・コーン・ポテト（と古い方式のトマト・カカオ）だけで、
  それ以外の食材の色は測っていないためです。
  （2026-09-14: 大豆・コーン・ポテトは測りずみなので、今の食材なら自動で当たります）
  （色のデータは vendor/pokesleep-vision/ingredients.js の
    PROTOTYPES というところに入っています。
    ここを増やすにはプログラムを動かして色を測る作業が必要で、
    ひとりで直すのはむずかしいです）

こうなります：
  ・SP、性格、サブスキルの自動読み取り  → これまでどおり動きます
  ・食材の自動読み取り                  → 当たらなくなります

対処：
  食材だけ、プルダウンで手で選んでください。
  それだけで点数は正しく出ます。

  参加者へのお知らせに、こう書いておくと親切です:
  「食材だけは自動で読み取れないので、
    Lv.30とLv.60のプルダウンをご自分で選んでください」


============================================================
 おまけ：ほかによく直したくなるところ
============================================================

■ ミュウが出てくる点数を変えたい（いまは600点）
  app.js をメモ帳で開いて、こう書いてある行を探す:
      const LAMP_THRESHOLD = 600;
  この 600 を好きな数字に変えて保存。→ 手順5もやること。

■ 食材の点数（AAA=100点 など）を変えたい
  scoring.js をメモ帳で開いて、こう書いてあるところを探す:
      const INGREDIENT_PATTERN_POINTS = {
        "AAA": 100,
        "ABB": 60,
        ...
  数字だけを書きかえて保存。→ 手順5もやること。

■ 色違いやFL10以内の点数を変えたい
  scoring.js の中の 350 や 100 という数字のところ。
  index.html の「★ 色違い (+350点)」という表示も
  同じように直さないと、画面の表示だけ古いままになります。
